# Poise 포이즈 — website

Public site for Poise, mental training for athletes: https://h00nster15.github.io/poise-site/

- Single file `index.html`, no build step. Push to `main` = live in ~1 minute.
- Sign-up form posts to the Wellperion Apps Script (`apps-script/Poise.gs` in the private wellperion-squash repo); rows land in the **Poise 대기자** tab of the app workbook and the owner gets an e-mail.
- `og.png` is the KakaoTalk/link preview image (1200x630).
- The app itself is at https://h00nster15.github.io/poise-web/.
